# K7 데이터 사전

> 참고용 12테이블 데이터 사전입니다. 현재 MVP 활성 정의는 `database/active-manifest.json`, `database/mvp/schema.sql`, `database/contracts/mvp_call_response.schema.json`을 따릅니다.

## 공통 규칙

- 식별자: `bigint GENERATED BY DEFAULT AS IDENTITY`
- 시간: 타임존을 포함하는 `timestamptz`
- 명명: 테이블·컬럼 모두 `snake_case`
- 수정 시각: 변경 가능한 테이블은 트리거로 `updated_at` 자동 갱신
- 테스트 데이터: 실제 금융고객·팀원 정보를 사용하지 않은 가상 데이터
- 위험 수준: `low` → `medium` → `high` → `critical`

## 1. `departments`

상담 담당 부서 기준정보입니다.

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| `department_id` | `bigint` | PK | 부서 식별자 |
| `department_code` | `text` | UNIQUE, NOT NULL, CHECK | 영문 소문자 업무 코드 |
| `department_name` | `text` | UNIQUE, NOT NULL, CHECK | 부서 표시명 |
| `is_active` | `boolean` | NOT NULL | 사용 여부 |
| `created_at` | `timestamptz` | NOT NULL | 생성 시각 |
| `updated_at` | `timestamptz` | NOT NULL | 최종 수정 시각 |

## 2. `customers`

원문 개인정보를 최소화한 고객 기본정보입니다.

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| `customer_id` | `bigint` | PK | 내부 고객 식별자 |
| `customer_number` | `text` | UNIQUE, NOT NULL, CHECK | 외부 노출 가능한 가상 고객번호 |
| `full_name_masked` | `text` | NOT NULL, CHECK | 마스킹 고객명 |
| `phone_masked` | `text` | NOT NULL, CHECK | 마스킹 전화번호 |
| `phone_lookup_hash` | `text` | UNIQUE, NOT NULL, CHECK | 전화번호 검색용 64자리 HMAC-SHA-256 값 |
| `account_number_masked` | `text` | CHECK | 마스킹 계좌번호 |
| `account_lookup_hash` | `text` | UNIQUE, CHECK | 계좌번호 검색용 64자리 HMAC-SHA-256 값 |
| `birth_year` | `smallint` | CHECK | 최소 식별용 출생연도 |
| `birth_date_masked` | `text` | CHECK | 마스킹 생년월일 |
| `customer_status` | `text` | NOT NULL, CHECK | `active`, `inactive`, `dormant` |
| `created_at` | `timestamptz` | NOT NULL | 생성 시각 |
| `updated_at` | `timestamptz` | NOT NULL | 최종 수정 시각 |

`account_number_masked`와 `account_lookup_hash`는 둘 다 있거나 둘 다 없어야 합니다. 해시는 운영에서 서버 비밀키 기반 HMAC으로 생성하며 API 응답에 포함하지 않습니다.

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| `counselor_id` | `bigint` | PK | 상담사 식별자 |
| `counselor_code` | `text` | UNIQUE, NOT NULL, CHECK | 사번 대체 업무 코드 |
| `counselor_name` | `text` | NOT NULL, CHECK | 상담사 표시명 |

| `employment_status` | `text` | NOT NULL, CHECK | `active`, `leave`, `inactive` |
| `created_at` | `timestamptz` | NOT NULL | 생성 시각 |

부서 삭제 시 상담사 참조를 보호하기 위해 `ON DELETE RESTRICT`를 사용합니다.

## 4. `counselor_permissions`

상담사별 현재 데이터 조회·관리 권한입니다.

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| `permission_id` | `bigint` | PK | 권한 식별자 |
| `counselor_id` | `bigint` | FK, NOT NULL | 권한 대상 상담사 |
| `permission_scope` | `text` | NOT NULL, CHECK | 정보 범위 |
| `access_level` | `text` | NOT NULL, CHECK | `masked_read`, `read`, `manage` |
| `granted_reason` | `text` | NOT NULL, CHECK | 권한 부여 사유 |
| `granted_by` | `bigint` | FK | 부여 담당 상담사/관리자 |
| `valid_from` | `timestamptz` | NOT NULL | 유효 시작 시각 |
| `valid_until` | `timestamptz` | CHECK | 유효 종료 시각 |
| `revoked_at` | `timestamptz` | CHECK | 회수 시각 |
| `created_at` | `timestamptz` | NOT NULL | 생성 시각 |
| `updated_at` | `timestamptz` | NOT NULL | 최종 수정 시각 |

회수되지 않은 권한에 한해 `counselor_id + permission_scope`가 UNIQUE입니다. 회수 후 새 권한 행을 추가할 수 있으므로 과거 부여 이력을 보존합니다. 권한 범위는 다음과 같습니다.

- `customer_basic`
- `consultation_history`
- `customer_cautions`
- `utterances`
- `model_analysis_results`
- `ai_consultation_cards`
- `routing_recommendations`
- `access_logs`

## 5. `consultation_sessions`

고객이 접수한 현재 상담 단위를 관리합니다.

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| `session_id` | `bigint` | PK | 상담 세션 식별자 |
| `external_session_key` | `text` | UNIQUE, NOT NULL, CHECK | 1~100자 전화·웹 시스템 연동 키 |
| `customer_id` | `bigint` | FK, NOT NULL | 고객 식별자 |
| `assigned_counselor_id` | `bigint` | FK | 배정 상담사 |
| `inquiry_type` | `text` | NOT NULL, CHECK | 문의 유형 |
| `session_status` | `text` | NOT NULL, CHECK | 세션 상태 |
| `channel` | `text` | NOT NULL, CHECK | `voice`, `chat`, `web` |
| `risk_level` | `text` | NOT NULL, CHECK | 현재 위험 수준 |
| `consent_to_record` | `boolean` | NOT NULL | 녹취 동의 여부 |
| `started_at` | `timestamptz` | NOT NULL | 접수 시작 시각 |
| `ended_at` | `timestamptz` | CHECK | 종료 시각 |
| `created_at` | `timestamptz` | NOT NULL | 생성 시각 |
| `updated_at` | `timestamptz` | NOT NULL | 최종 수정 시각 |

문의 유형을 아직 분류하지 못한 초기 상태는 `unclassified`를 사용합니다. 세션 상태는 `waiting`, `analyzing`, `ready`, `in_progress`, `summarizing`, `wrap_up`, `completed`, `cancelled`입니다. 고객 삭제는 `RESTRICT`, 상담사 삭제는 세션 보존을 위해 `SET NULL`입니다.

## 6. `utterances`

세션 내 발화 원문 암호문과 마스킹 텍스트를 분리합니다.

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| `utterance_id` | `bigint` | PK | 발화 식별자 |
| `session_id` | `bigint` | FK, NOT NULL | 상담 세션 |
| `speaker_type` | `text` | NOT NULL, CHECK | `customer`, `system`, `counselor` |
| `sequence_no` | `integer` | NOT NULL, CHECK | 세션 내 발화 순서 |
| `transcript_ciphertext` | `bytea` | CHECK | 애플리케이션/KMS 암호화 원문 |
| `encryption_key_version` | `text` | CHECK | 암호화 키 버전 |
| `masked_transcript` | `text` | NOT NULL, CHECK | 일반 조회용 마스킹 발화 |
| `contains_sensitive_data` | `boolean` | NOT NULL | 민감정보 탐지 여부 |
| `stt_confidence` | `numeric(5,4)` | CHECK | 0 이상 1 이하 STT 신뢰도 |
| `spoken_at` | `timestamptz` | NOT NULL | 발화 시각 |
| `created_at` | `timestamptz` | NOT NULL | 생성 시각 |
| `updated_at` | `timestamptz` | NOT NULL | 최종 수정 시각 |

`session_id + sequence_no`는 UNIQUE입니다. 암호문과 키 버전은 함께 존재해야 합니다. 녹취 미동의 세션에는 암호문을 저장할 수 없으며 마스킹 발화만 저장합니다. 일반 화면은 `masked_transcript`만 사용합니다.

## 7. `model_analysis_results`

최신 음성 기반 감정온도 모델의 세션별 추론 결과입니다.

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| `analysis_result_id` | `bigint` | PK | 모델 결과 식별자 |
| `session_id` | `bigint` | FK, NOT NULL | 상담 세션 |
| `result_key` | `text` | UNIQUE, NOT NULL, CHECK | 모델 재전송 중복 방지용 외부 결과 키 |
| `model_name` | `text` | NOT NULL, CHECK | 모델명 |
| `model_version` | `text` | NOT NULL, CHECK | 모델 버전 |
| `output_schema_version` | `text` | NOT NULL, CHECK | JSON 계약 버전 |
| `analysis_status` | `text` | NOT NULL, CHECK | `completed`, `unavailable`, `failed` |
| `emotion_temperature_score` | `numeric(5,2)` | CHECK | 성공 시 0~100 감정온도 |
| `emotion_temperature_level` | `text` | CHECK | 성공 시 `stable`, `caution`, `elevated` |
| `voice_arousal_score` | `numeric(5,2)` | CHECK | 0~100 각성도 |
| `voice_dominance_score` | `numeric(5,2)` | CHECK | 0~100 지배성 보조값 |
| `voice_valence_score` | `numeric(5,2)` | CHECK | 0~100 정서가 보조값 |
| `negative_activation_score` | `numeric(5,2)` | CHECK | 0~100 부정 활성도 보조값 |
| `audio_quality` | `text` | NOT NULL, CHECK | 음성 품질 코드 |
| `failure_code` | `text` | CHECK | 사용 불가·실패 시 원인 코드 |
| `generated_at` | `timestamptz` | NOT NULL | 추론 시각 |
| `created_at` | `timestamptz` | NOT NULL | 생성 시각 |
| `updated_at` | `timestamptz` | NOT NULL | 최종 수정 시각 |

`completed`일 때만 점수와 등급이 존재합니다. `unavailable`·`failed`일 때 점수는 NULL이고 `failure_code`가 필수입니다. 점수 구간은 `stable` 0~33, `caution` 33 초과~66, `elevated` 66 초과~100이며 화면에는 안정·주의·고조로 표시합니다. 모델은 음성만 입력으로 사용하고 고객정보·과거 상담·STT 텍스트는 입력에 포함하지 않습니다. 음성 파일 경로도 이 테이블에 저장하지 않습니다.

## 10. `customer_cautions`

단순 blacklist 여부가 아닌 구조화된 고객 주의정보입니다.

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|

| `customer_id` | `bigint` | FK, NOT NULL | 고객 식별자 |
| `caution_type` | `text` | NOT NULL, CHECK | 주의 유형 |
| `reason` | `text` | NOT NULL, CHECK | 등록 사유 |
| `severity` | `text` | NOT NULL, CHECK | 심각도 |
| `caution_status` | `text` | NOT NULL, CHECK | `active`, `expired`, `revoked` |
| `registered_by` | `bigint` | FK | 등록 상담사/관리자 |
| `registered_at` | `timestamptz` | NOT NULL | 등록 시각 |
| `expires_at` | `timestamptz` | CHECK | 만료 시각 |
| `created_at` | `timestamptz` | NOT NULL | 생성 시각 |
| `updated_at` | `timestamptz` | NOT NULL | 최종 수정 시각 |

주의 유형은 `fraud_suspected`, `abusive_behavior`, `repeated_dispute`, `additional_review_required`, `vulnerable_customer`, `other`입니다.

## 11. `routing_recommendations`

세션별 후보 부서·상담사와 선택 결과를 순위로 저장합니다.

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| `routing_id` | `bigint` | PK | 추천 식별자 |
| `session_id` | `bigint` | FK, NOT NULL | 상담 세션 |
| `recommended_department_id` | `bigint` | FK, NOT NULL | 추천 부서 |
| `recommended_counselor_id` | `bigint` | FK | 추천 상담사 |
| `recommendation_rank` | `smallint` | NOT NULL, CHECK | 세션 내 추천 순위 |
| `confidence` | `numeric(5,4)` | NOT NULL, CHECK | 0 이상 1 이하 신뢰도 |
| `rationale` | `text` | NOT NULL, CHECK | 추천 근거 |
| `selected` | `boolean` | NOT NULL | 최종 선택 여부 |
| `model_name` | `text` | NOT NULL, CHECK | 라우팅 모델명 |
| `model_version` | `text` | NOT NULL, CHECK | 라우팅 모델 버전 |
| `created_at` | `timestamptz` | NOT NULL | 생성 시각 |
| `updated_at` | `timestamptz` | NOT NULL | 최종 수정 시각 |

`session_id + recommendation_rank`는 UNIQUE이며, 부분 UNIQUE 인덱스로 세션당 `selected = true`는 최대 1건입니다. 추천 상담사와 추천 부서는 복합 FK로 연결되어 실제 소속이 다른 조합을 차단합니다.

## 12. `access_logs`

고객정보 접근 감사로그입니다. 생성 후 UPDATE·DELETE가 트리거로 차단됩니다.

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| `access_log_id` | `bigint` | PK | 로그 식별자 |
| `counselor_id` | `bigint` | FK, NOT NULL | 조회자 |
| `customer_id` | `bigint` | FK, NOT NULL | 조회 대상 고객 |
| `session_id` | `bigint` | 복합 FK | 관련 상담 세션 |
| `information_scope` | `text` | NOT NULL, CHECK | 조회 정보 범위 |
| `action_type` | `text` | NOT NULL, CHECK | `view`, `export`, `create`, `update` |
| `access_purpose` | `text` | NOT NULL, CHECK | 업무상 조회 목적 |
| `result_status` | `text` | NOT NULL, CHECK | `success`, `denied`, `error` |
| `request_id` | `text` |  | API 요청 추적 ID |
| `source_ip` | `inet` |  | 요청 출발지 IP |
| `created_at` | `timestamptz` | NOT NULL | 접근 시각 |
| `updated_at` | `timestamptz` | NOT NULL, CHECK | 생성 시각과 동일한 불변값 |

`session_id + customer_id` 복합 FK로 다른 고객의 세션을 잘못 기록하는 것을 방지합니다. 로그 본문에는 고객정보 원문이나 발화 내용을 저장하지 않습니다.
