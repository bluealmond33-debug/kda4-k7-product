# 시연용 오디오 — 여기에 파일을 넣으면 그대로 재생됩니다

이 폴더는 **비어 있어도 데모가 돌아갑니다.** 파일이 없거나 브라우저가 자동재생을 막으면
조용히 넘어가고 화면 흐름만 진행됩니다(`.play().catch(() => {})`). 그래서 녹음이 준비되기
전에도 시연할 수 있고, 준비되면 파일만 떨어뜨리면 됩니다 — 코드는 고치지 않습니다.

## AI 사전 접수 안내 — `ars/`

고객이 전화를 걸면 KARI-NA가 말하는 내용입니다. **대본은 코드가 아니라
[`src/data/arsScript.ts`](../../src/data/arsScript.ts)에 있습니다** — 화면(전사 패널의 AI
말풍선)과 음성이 같은 원본을 쓰므로 둘이 어긋나지 않습니다.

### 넣는 방법 — 파일만 떨어뜨리면 끝입니다

**대본의 `id`가 곧 파일명입니다.** `ars/<id>.mp3` 로 두면 코드를 고치지 않아도 잡힙니다.

| 파일 | 대사 | 언제 |
|---|---|---|
| `ars/greet-1.mp3` | 안녕하세요, 키움은행 고객센터입니다. | 통화 연결 직후 |
| `ars/greet-2.mp3` | 번호를 누르지 않으셔도 됩니다… | 이어서 |
| `ars/greet-3.mp3` | 말씀하신 내용은 상담사에게 먼저 전달돼요… | 이어서 |
| `ars/confirm-1.mp3` | 더 말씀하실 내용이 있으신가요? | 말이 끊긴 뒤 |
| `ars/confirm-2.mp3` | 말씀이 끝나셨으면 우물정자(#)를 눌러 주세요… | 이어서 |
| `ars/handoff-1.mp3` | 상담 카드로 정리해 담당 부서에 전달했습니다. | 요약 완료 |
| `ars/handoff-2.mp3` | 잠시 기다리시면 상담사를 연결해 드립니다… | 이어서 |

### 길이를 맞출 필요가 없습니다

**재생이 끝나는 시점이 다음 말풍선을 띄웁니다.** 그래서 녹음이 길든 짧든 말풍선과 목소리가
저절로 맞습니다 — `arsScript.ts`의 `sec`은 **녹음이 없는 줄에만** 쓰이는 대체 간격입니다.
일부만 녹음돼 있어도 섞여서 잘 돌아갑니다(있는 줄은 음성이, 없는 줄은 `sec`이 이끕니다).

문구만 바꾸고 싶으면 `arsScript.ts`의 `text`만 고치면 됩니다. 줄을 더하거나 빼도 되고,
그때 파일명도 새 `id`에 맞춰 두면 됩니다.

재생은 **고객 폰 화면(`?role=customer`)에서만** 일어납니다. 직원 창에도 같은 안내가 글로
뜨지만 소리는 내지 않습니다 — 창을 두 개 열어 두면 같은 안내가 겹쳐 들리기 때문입니다.

## 통화 녹취 — `recording.mp3`

후처리 화면(WrapSheet)의 녹취 재생바가 씁니다. 파일이 없으면 재생바가 빈 상태로 보입니다.
실제 상담 음성이 아니라 **시연용 샘플**을 쓰세요.

## 주의 — 보안 컨텍스트

브라우저는 사용자가 화면을 한 번이라도 클릭한 뒤에야 소리를 허용합니다. 시연에서 고객이
전화 버튼을 누르는 것이 그 클릭이 되므로 보통은 문제가 없습니다. 다만 **마이크**(주황 점·파형)는
`localhost` 또는 `https`에서만 열립니다 — LAN `http://192.168.x.x`로 열면 브라우저가 막습니다.
