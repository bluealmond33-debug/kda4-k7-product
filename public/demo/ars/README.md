# ARS 안내 음성 — 녹음 파일 자리

이 폴더에 아래 **3개 파일**을 넣으면 시연에서 AI 안내 음성이 나갑니다.
**파일이 없으면 조용히 텍스트만 흐릅니다**(에러 없음) — 그래서 지금도 시연 자체는 동작하지만, 소리가 없습니다.

- 재생 주체: `src/lib/arsDialogue.ts` (`new Audio("/demo/" + line.audio)`)
- 대본 원본: `src/data/arsScript.ts` — **문구를 바꾸려면 저 파일을 고치고 여기 녹음도 다시** 하세요.
- 형식: mp3 / 모노 / 44.1kHz면 충분합니다. 여성 상담 음성 톤 권장.

> 파일명은 정확히 아래대로여야 합니다. 대소문자·하이픈까지 일치해야 합니다.

---

## 1. 통화 연결 직후 — `connecting` 단계 (greet-1 하나로 고정, ~14.5초)

인사·AI소개·용건요청·"# 눌러주세요" 안내를 한 줄에 다 담아서 greet-1 하나로 끝낸다
(별도의 greet-2/greet-3·confirm 안내 없음).

| 파일 | 길이(목표) | 대사 |
|---|---|---|
| `greet-1.mp3` | 14.5초 | 안녕하세요, 키움은행입니다. 에이아이 상담 도우미가 안내해 드립니다. 정확한 안내를 위해 문의하실 내용을 편하게 말씀해 주세요. 상담사에게 전달할 내용을 정리해 드립니다. 말씀을 다 마치면 우물 정자를 눌러주세요. |

## 2. 요약·전달 완료 — `prep` 단계

| 파일 | 길이(목표) | 대사 |
|---|---|---|
| `handoff-1.mp3` | 4초 | 말씀하신 내용을 상담 카드로 정리해 담당 부서에 전달했습니다. |
| `handoff-2.mp3` | 8초 | 잠시 기다리시면 상담사를 연결해 드립니다. 지금 통화를 종료하셔도 접수는 그대로 남아, 담당 상담사가 확인 후 콜백드립니다. |

---

## 길이가 중요합니다

`sec` 값이 **다음 말풍선이 뜨는 간격**입니다(`arsScript.ts`). 녹음이 표기된 길이보다 길면
음성이 끝나기 전에 다음 자막이 올라가 어긋나 보입니다.

- 녹음이 길어졌으면 → `src/data/arsScript.ts`의 `sec`을 실제 길이에 맞춰 올리세요.
- 반대로 짧아졌으면 → 굳이 줄이지 않아도 됩니다(빈 시간이 조금 생길 뿐).

## 확인 방법

고객 화면(`?role=customer`)에서 통화 버튼을 누르면 1번 그룹이 재생됩니다.
소리가 안 나면:

1. 파일명이 정확한지 (`greet-1.mp3`, 하이픈·숫자 확인)
2. 브라우저 자동재생 정책 — 통화 버튼 클릭에서 시작하므로 보통 통과하지만, 콘솔에
   `NotAllowedError`가 뜨면 페이지를 한 번 클릭한 뒤 다시 시도
