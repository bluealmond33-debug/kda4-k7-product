## 0. 읽는 법

부서 하나가 **두 축**을 동시에 가진다.

```
부서 ─┬─ 라우팅  : 어떤 용건(task_code)이 여기로 배정되나 → S/G/E · handler
      └─ RAG    : 어떤 문서(business_code)를 검색하나    → 문서 · 청크
             두 축을 잇는 다리 = business_code
```

- 라우팅 표의 `→ business_code` 열이 **다리**다. 용건이 배정되면 그 코드로 문서를 검색한다.
- 문서에는 `task_code`를 붙이지 않는다. 문서 1건이 여러 용건에 답하기 때문(N:1).
- **S/G/E는 검색에 쓰이지 않는다.** 검색 SQL 필터는 `category`(부서·business_code) 하나뿐이다.
