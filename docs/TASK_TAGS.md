## 태그 용도

각 업무코드에 붙는 태그는 **두 가지 용도**로 나뉜다.

| 용도 | 쓰는 태그 | 하는 일 |
|---|---|---|
| **라우팅**(배정) | `task_code` · `S/G/E` · `부서` · `handler` | 통화를 누구에게 보낼지 |
| **RAG**(검색) | `부서` · `business_code` | 어떤 규정을 찾을지 |

```
task_code ─┬─ S/G/E   ─┐
           ├─ handler ─┴─→ 라우팅: 배정
           ├─ 부서     ──→ 양쪽 공통 (다리)
           └─ business_code ──→ RAG: 검색
```

- **`task_code`가 마스터 키다.** 나머지 태그는 전부 여기서 조회된다.
- **부서가 양쪽에 공통**이라 배정과 검색을 잇는 다리 역할을 한다.
- **S/G/E는 검색에 쓰이지 않는다.** 검색 필터는 `부서`·`business_code`뿐이다.
- **문서에는 `task_code`를 붙이지 않는다.** 문서 1건이 여러 용건에 답하기 때문(N:1).
  예) 대출 상품설명서 1건 → `S005`·`G002`·`G008`·`G009` 모두 커버.
  그래서 문서에는 묶음 단위인 `business_code`를 태깅한다.
