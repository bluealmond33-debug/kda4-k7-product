### B2. 주민번호 마스킹 안 됨 — **P0**
- **원문**: "계좌번호는 되고 주민번호는 마스킹 안됨 → 자릿수 상관없이 마스킹되도록"
- **상태**: 🔴 미처리. `pii_guard.py:49` 패턴이 **초판과 동일**하다.
  ```python
  ("rrn", re.compile(r"(?<!\d)(\d{6})[-\s]?([1-4]\d{6})(?!\d)"))
  ```
  정확히 6+7자리, 뒷자리 첫 숫자 1~4를 요구한다. STT가 "880214 123 4567"처럼 끊어 적으면 매칭 실패.
  계좌(`:66~70`)는 `계좌\s*번호` **문맥어 + 8자리 이상** 규칙이 따로 있어 잡혔던 것이다.
- **조치**: 계좌와 같은 방식으로 문맥어 규칙을 **우선순위 최상단**에 추가.
  ```python
  (주민|주민등록|주민번호|앞자리|뒷자리)[^\d\n]{0,8}(?:\d[-\s,]?){5,}\d
  ```
  모듈 원칙("애매하면 마스킹", docstring 11행)에 부합한다.
- **파일**: `backend/app/services/pii_guard.py:47~70`

- `normalize_department()` — 모르는 이름이면 None을 돌려 호출부가 '필터 없음'을 **의식적으로** 고르게 (조용히 풀리지 않게)
