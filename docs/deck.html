직접 조사해보니 바로 갖다 쓸 온프레미스 방언 모델이 업계에 없었습니다. 유일한 길인 파인튜닝은 데이터 승인·학습 시간 때문에 이번 발표까진 무리였습니다.

그래서 근거 없이 부풀리는 대신 측정된 한계 + 로드맵으로 가져왔습니다. 다음은 방언 데이터 확보 → 파인튜닝, 실시간 위험 신호 고도화, 규정집 전체 연동입니다.
