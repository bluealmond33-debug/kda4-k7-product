# 데모 투어링 (시연·발표 전용)

앱 위에 얹히는 **분리된 안내 레이어**입니다. 스팟라이트(영역만 밝게) + 말풍선(영역을 가리키며 설명)으로
대기→접수→준비→통화→후처리 한 바퀴를 안내합니다. 시작 시 사용자가 "투어 따라가기 / 자유 체험"을 고릅니다.

## 구조

- `steps.ts` — 투어 '대본'. 화면별 스텝(앵커·제목·설명·배치). 문구 수정은 여기서만.
- `DemoTour.tsx` — 렌더러. `TourChooser`(시작 선택) + `DemoTour`(스팟라이트·말풍선).
- 앱 쪽 접점은 두 가지뿐:
  1. `LiveDemo.tsx`의 `<TourChooser/>`·`<DemoTour/>` 마운트 (몇 줄)
  2. 각 컴포넌트에 심어둔 `data-tour="..."` 앵커 속성 (렌더링에 아무 영향 없음)

## 실제 제품에서 제거하려면

1. `LiveDemo.tsx`에서 투어 상태(`tourMode`·`tourRun`)와 `<TourChooser/>`·`<DemoTour/>` 마운트 삭제
2. `src/tour/` 폴더 삭제
3. (선택) `data-tour` 속성 제거 — 남겨둬도 무해

투어 로직·문구는 앱 컴포넌트 안에 없으므로 위 두 단계로 완전히 사라집니다.
